# Установка и откат

## Установка

1. Полностью закройте DOOM: The Dark Ages.
2. Скачайте `Thanos-wrapper-v0.1.0-pascal.1-windows-x64.zip` со [страницы релиза](https://github.com/4erk/Thanos_wrapper/releases/tag/v0.1.0-pascal.1).
3. Найдите папку с `DOOMTheDarkAges.exe`. Сохраните отдельно уже имеющиеся `vulkan-1.dll`, `vulkan-1_real.dll` и `Thanos-wrapper.ini` перед заменой.
4. Скопируйте `C:\Windows\System32\vulkan-1.dll` **в папку игры** под именем `vulkan-1_real.dll`. Исходный системный файл оставьте на месте.
5. Скопируйте `vulkan-1.dll` и `Thanos-wrapper.ini` из архива в папку игры.
6. Запустите игру. Для первой проверки оставьте FSR выключенным. Дождитесь загрузки и появления 3D-сцены.

Ожидаемое расположение:

```text
DOOMTheDarkAges.exe
vulkan-1.dll          <- из этого релиза
vulkan-1_real.dll     <- копия вашего системного Vulkan loader
Thanos-wrapper.ini   <- из этого релиза
```

Системный Vulkan loader не входит в архив. Используется версия, уже установленная на вашем ПК. Установка драйверов, модов и правка EXE не требуются.

## Настройки обёртки

Релизный INI включает `PascalRTGate=1`. Сохранение шейдеров отключено; обычный текстовый лог остаётся включён.

Для диагностики можно указать уже существующую папку:

```ini
[experiments]
PascalRTGate=1
[diagnostics]
ShaderDumpDirectory=C:\DoomDiagnostics\shaders
```

Лимит захвата — 256 MiB на процесс. Пустой `ShaderDumpDirectory` отключает сохранение шейдеров. Переменные окружения `THANOS_PASCAL_RT_GATE` и `THANOS_SHADER_DUMP_DIR` имеют приоритет над INI.

## Чёрный экран / только курсор

После изменения FSR или динамических настроек верните прежние значения и перезапустите игру. Если меню недоступно, сначала сохраните резервную копию настроек в `Saved Games\id Software\DOOMTheDarkAges`. Сброс всех настроек затрагивает также управление; не удаляйте весь каталог сохранений.

Убедитесь, что установлена DLL этого релиза, а не один из старых ZIP-файлов в корне репозитория. Если сцена не появляется после загрузки, приложите к issue конфигурацию, шаги воспроизведения и соответствующие строки `vkproxy_<PID>.log`.

## Удаление / откат

Закройте игру. Уберите из её папки добавленные этим релизом `vulkan-1.dll`, `vulkan-1_real.dll` и `Thanos-wrapper.ini`. Если до установки была другая обёртка, восстановите её сохранённые файлы. Системные файлы и сохранения для удаления обёртки менять не нужно.

## Проверка архива

SHA-256 архива опубликован в `SHA256SUMS.txt` рядом с релизом. Контрольные суммы содержимого находятся внутри архива в `SHA256SUMS.files.txt`.

```powershell
Get-FileHash .\Thanos-wrapper-v0.1.0-pascal.1-windows-x64.zip -Algorithm SHA256
```
